# Support

Welcome! This page explains how to get help, report problems, and connect with the community around django-react-autopilot-test.

## Reporting Issues

If you find a bug or something isn't working as expected, please [open an issue on GitHub](https://github.com/Samiullah324/django-react-autopilot-test/issues). Include:

- A clear description of the problem and steps to reproduce it
- Expected vs. actual behavior
- Your environment (OS, Python/Node versions, Docker if relevant)

## Getting Help

For questions, setup help, or general discussion, use [GitHub Discussions](https://github.com/Samiullah324/django-react-autopilot-test/discussions). Search existing threads first—you may find your answer already covered.

## Documentation

See the [README](README.md) for setup, architecture, API overview, and local development. Interactive API docs are available at `/api/docs/` when the backend is running.

## Community Guidelines

When asking for help:

- Be specific about what you're trying to do and what went wrong
- Share relevant error messages or logs (redact secrets)
- Describe what you've already tried
- Be patient and respectful—maintainers and contributors volunteer their time
